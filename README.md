# CineDock Distribution

The public distribution channel for **CineDock**, a Windows-first media center
in private development.

**No public release is approved or available yet.** This repository currently
contains documentation only, not downloadable builds, signatures, or a completed
corresponding-source release. A successful build or signing workflow alone does
not establish release readiness.

## Distribution documentation

- [Release catalog and publication gates](docs/releases.md): edition names,
  current availability, acceptance boundaries, and the coordinated release lane.
- [Verification](docs/verification.md): exact-byte SHA-256 and Sigstore checks,
  the approved signer identity, and what those checks do not prove.
- [Licensing and corresponding source](docs/licensing-and-source.md): required
  source access and the unresolved combined-binary licensing gate.

Future approved releases are intended to carry edition ZIPs, verification
materials, notices, and the complete required corresponding-source materials.
Development remains in the private source repository; required release source
snapshots will be public here when approved. A private development repository is
not a substitute for recipients' access to corresponding source.

The unlocked **OwnerTest** build is private and is not a public release or a
download offered by this channel. Do not upload owner previews, credentials,
profiles, personal media, or unredacted diagnostics to this repository.

Sunshine/Moonlight, controller navigation, Live60/high-frame-rate paths, Google
Drive, and physical-device compatibility have separate acceptance requirements.
Their presence in development code is not a claim that they are fully verified
or available in a particular edition.
